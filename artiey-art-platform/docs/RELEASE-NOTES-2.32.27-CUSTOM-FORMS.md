# تکمیل فرم‌ساز اعضای Artiey — بسته تکمیلی 2.32.27

## قابلیت‌های اضافه‌شده
- تعریف حداکثر ۲۰ فیلد سفارشی برای هر نقش از صفحه «فرم ثبت‌نام اعضا» در پیشخوان.
- پشتیبانی از text، email، tel، url، textarea، number، date، select و checkbox.
- اعتبارسنجی سمت سرور، محدودسازی نام فنی و نوع فیلد، پاک‌سازی عنوان‌ها و گزینه‌ها و رد فیلدهای ناشناخته.
- ذخیره داده‌های سفارشی در user meta با کلیدهای namespaced و بدون افزودن ستون یا تغییر ساختار جداول موجود.
- نمایش و ویرایش فیلدهای سفارشی در فرم ثبت‌نام و فرم ویرایش پروفایل.
- سازگاری با هاست‌هایی که PHP MBString ندارند.

## روش استفاده
1. در پیشخوان وردپرس به «فرم ثبت‌نام اعضا» بروید.
2. در کارت نقش موردنظر، بخش «فیلدهای اختصاصی این نقش» را پیدا کنید.
3. JSON فیلدها را وارد کنید و تنظیمات را ذخیره کنید.
4. فیلدهای جدید در ثبت‌نام همان نقش و ویرایش پروفایل اعضای آن نقش نمایش داده می‌شوند.

نمونه:
```json
[
  {
    "name": "portfolio_url",
    "label": "لینک نمونه‌کار",
    "type": "url",
    "required": false,
    "max": 300
  },
  {
    "name": "experience_level",
    "label": "سطح تجربه",
    "type": "select",
    "required": true,
    "options": {
      "emerging": "نوظهور",
      "professional": "حرفه‌ای"
    }
  }
]
```

## محدودیت‌ها و ملاحظات
- این نسخه فرم‌ساز قابل مدیریت با JSON امن در پیشخوان است؛ هنوز رابط Drag & Drop بصری ندارد.
- فیلدهای سفارشی در user meta ذخیره می‌شوند و به‌صورت خودکار به ستون‌های اختصاصی جداول هنرمند/گالری/حراج تبدیل نمی‌شوند.
- برای نمایش فیلدهای سفارشی در صفحات عمومی، ویجت‌های Elementor، Schema یا API باید اتصال نمایشی جداگانه تعریف شود.
- پیش از به‌روزرسانی سایت اصلی، از پایگاه داده و فایل‌ها نسخه پشتیبان تهیه و ابتدا روی staging نصب شود.
